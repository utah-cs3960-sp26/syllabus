# About the Course

The goal of the class is to teach you how to work effectively with
modern AI coding agents. By the end you will:

- Understand the basics of how AI coding agents work
- Understand how to establish an effective context for AI coding
- Understand how to develop an AI-focused testing approach
- Understand how to create modularity to scale AI coding
- Develop workflows to leverage the strengths of AI and human coders

Students are expected to be experienced programmers and should expect
to write a significant amount of code. Expect to spend roughly 5 hours
per week coding outside of class. Competence with some programming
language, git, the command line, and some text editor is expected.

This is an experimental class, never taught before, on a rapidly
shifting topic. Instructors reserve the right to change the syllabus
at will, with in-class notice.

# Assessment

Grades will be 60% assignments, 30% activities, and 10% readings.

Given the experimental nature of the class, the instructors expect
students to put significant effort into the class. With AI tools it's
really easy to fool yourself into thinking you're almost done when
you've just started, or that you can do the assignment quickly when
you can't. *If you put effort into the class, you will get an A. But
the instructors will have little patience for students trying to skate
on minimal effort.*

**Assignments**: Assignments will build large, complex applications.
For example, the first assignment will build a text editor. AI coding
tools are *mandatory*. Most assignments will be individual---student
plus AI---but some later ones might be done in groups, at instructor
discretion.

Assignments will build project week over week. Maintaining large
software projects over time, without the AI breaking older features or
making the code impossible to work with, is a major theme of the
class. Students should not fall behind.

AI tools make it easy to build brittle prototypes very quickly. What's
hard is handling edge cases, dealing with interaction between
features, and applying some taste to make sure the software works
well. Students will only get credit for the latter! Specifically, most
assignments will be graded on functionality, though later assignments
may instead be graded on other metrics like test coverage.

**Activities**: In-class activities will be done in groups and
demonstrate some small aspect of AI assisted coding. They will be
graded in class and largely pass/fail on effort.

Attendance is therefore mandatory. If you must be absent, you must
inform the instructors before class for it to be excused.

**Readings**: No one has more than a year's experience with AI coding,
so workflows and knowledge evolve and learning from others is key.
Readings will cover a variety of topics but focused on effective use
of AI coding agents. Students must do the reading and leave comments
in Perusall.

# Topics

Planned course topics include:

- **AI basics**: tokens, models, training, and agents
- **Context**: prompts, tool use, thinking, compaction, sub-agents
- **Testing**: unit, integration, coverage, fuzzing, properties
- **Modularity**: interfaces, refactoring, equivalence, migration
- **Workflows**: debugging, refactoring, research

Given the evolving field, no schedule is planned up front, and topics
may change without notice.

# Policies

**AI**: AI use is allowed and, in fact, mandatory.

**Late policy**: Automatic two-day extension (from Friday to Sunday
night) on all assignments and readings. Activities must be performed
in class, so cannot be late, but absences can be excused by informing
the instructors before class begins.

**Rudeness**: Disruptive, belittling, or rude behavior will not be
tolerated, including online. Punishment will vary by severity but can
include expulsion from the class.

**Cheating**: Sharing or submitting another student's code or using
another student's prompt is cheating. Submitting code found online is
too, but using prompts found online is fine.

Amp records and makes available to instructors complete logs of all AI
interactions. Instructors will examine those logs to prevent cheating.
Absence of logged work will be grounds for failing the assignment or,
depending on severity, the class as a whole.
